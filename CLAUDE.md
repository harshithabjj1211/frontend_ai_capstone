# Project Rules

## Rule 1
Use `react-hook-form` for all forms instead of uncontrolled inputs.

## Rule 2
Use Zod for all form validation and keep validation rules in a schema.

## Rule 3
Disable the **Save Settings** button until the form is valid.

## Rule 4
Every form input must have an accessible label and inline validation messages.

## Rule 5
Use semantic HTML and accessibility attributes such as `aria-invalid`, `aria-describedby`, and `role="alert"` for validation errors.
